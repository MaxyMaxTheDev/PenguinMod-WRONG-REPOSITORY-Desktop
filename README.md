# Where is PenguinMod Desktop?

If you came to this repository expecting PenguinMod desktop and a download link, sorry! :(

We have not made a desktop app yet. This repository was just a fork of TurboWarp's desktop app that has NOT been edited to work with PenguinMod.

Please be patient with us. We'll provide links to our real desktop project here once possible.

# When is it coming out?
PenguinMod Desktop does not have a formal release date yet, as it is still actively being built. You can track ongoing code changes and updates through the official [PenguinMod Wiki](https://wiki.penguinmod.com/wiki/PenguinMod_desktop), which as of now (July 23, 2026) is going crazy. <img width="1027" height="704" alt="image" src="https://github.com/user-attachments/assets/ae268e37-be9f-41fd-8894-992b0682e833" />
